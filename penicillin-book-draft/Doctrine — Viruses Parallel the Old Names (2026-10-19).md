# Doctrine — Viruses Parallel the Old Names; the Names Dictate Treatment (2026-10-19)

**Status:** his doctrine, filed as his.
**Frame:** *The Mycelial Transposition* — educational manuscript reference only. Never medical advice.

## His doctrine [H]

Viruses are supposed to parallel the old disease names — and the information in between is what's used to form treatment plans based upon more advanced data. However, the names themselves dictate a treatment.

## The three parts

1. **Viruses parallel the old names** [H, prescriptive — "supposed to"]. The virus and the old (American) disease name should line up side by side. This is his doctrine for how the system ought to be ordered, not a description of the current record.
2. **The in-between informs treatment** [H]. The information between the virus and the name — the chain with things stuck to it: serotypes, titers, elements — is what treatment plans get formed from, using more advanced data.
3. **The names dictate treatment** [H]. The disease name itself determines the treatment. Start and stop at the name (his earlier doctrine) — and the name issues the orders.

## Against the record

- **"Supposed to" is doing real work.** In the record, viruses and old names do NOT parallel cleanly: one virus wears many names (VZV → chickenpox and shingles), one name covers many viruses ("common cold" → rhinoviruses, coronaviruses, adenoviruses). The parallel is his prescription, not the current description [D].
- **Names dictating treatment: strong foothold** [H→D]. Medicine genuinely runs diagnosis → protocol: "strep throat" triggers antibiotics, "influenza" triggers antivirals and isolation, ICD codes determine what treatment gets covered. The name issuing the treatment is how the system already operates — his Chapter 6 "action the label triggers" filed exactly this.
- **In-between data guiding treatment: foothold** [H→D]. Cultures and susceptibilities, titers and panels — the information between name and agent — genuinely shape therapy in practice.

## Verdict

Part 1 is his doctrine for the reordered system (filed as his). Parts 2 and 3 describe machinery medicine already uses — the name triggering the protocol, the in-between data shaping it. His doctrine takes the existing machinery and puts the old names back in charge of it.
