# Thesis Note — Additive Naming: Renaming Adds an Alias

**Filed:** 2026-10-18 · For *The Mycelial Transposition* (nomenclature chapters)
**Source:** Douglas's dictation, main chat, ~12:23 AM CDT

## His claim (his words, lightly cleaned)

"If names are added, we're not actually renaming shit — you're actually just adding a new name to help make it more possible to find the same thing. And that's what I think is being forgotten. Because if we're inspired to add more to what's there, it's supposed to be globbed into groups, like I'm trying to do, to make it so that it's easier to figure out."

## The thesis, stated plainly

A taxonomic "rename" is a misnomer. What actually happens is **additive naming**: a new name joins the old one as an alias, and the aliases are globbed into a synonym group around the organism. The purpose of the addition is findability — more names pointing at the same thing make it easier to locate, not harder. The glob (synonym group) is the unit, not the single name.

## Why it matters to the manuscript

- This reframes the whole adoption-spectrum argument. The fight was never "old name vs. new name" — it is "one alias vs. a glob of aliases." The retention case (ISHAM working group, filed 2026-10-14) fears the *reported* name changing; the additive thesis answers that the old name never dies, it joins the glob.
- Direct lineage: the "lab reports the name it chooses" note (2026-10-10), the adoption-spectrum decision (2026-10-11), the ICD-11 billing-layer note (2026-10-12), the formal retention case (2026-10-14). This thesis is the capstone claim over all four.
- Placement: ch 6 (nomenclature audit — the calibration setting: "what does the name do?"), intro (the three postures restated as alias postures).

## Honest anchors (do not drop)

1. **The infrastructure already works this way.** NCBI Taxonomy, MycoBank, GBIF all retain old names as synonyms — the old name remains findable after a rename. His "globbed into groups" describes actual database practice. This is the documented foothold.
2. **The pushback it must survive:** the clinic does not run on databases. One name goes on the lab report, and that is the name the doctor acts on. The ISHAM group's fear is not that *Candida auris* becomes unfindable — it is that the *reported* name changes under people's feet. The thesis needs the split: **findability** (aliases, globbed — his thesis holds) vs. **the used name** (one name on the report — the retention case holds). Both can be true; the book should say so.
3. **Formally, it is still a rename.** The accepted name changes; the old becomes a synonym. His claim is about what renaming *does* (adds an alias), not what it is called. Keep the wording honest: "renaming adds; it does not erase."
4. Manuscript material only — no clinical recommendation follows from this.

## Sparring — one honest line per claim (added 2026-10-18, tested three ways)

**How tested:** (1) database layer — NCBI/MycoBank/GBIF synonym retention; (2) lab-report layer — CAP Today 2026-03-10 note + ISHAM retention reply 2026-10-14 note; (3) billing/record layer — ICD-11 mycoses note 2026-10-12. Manuscript frame only.

1. "Renaming isn't renaming, it's adding an alias" — **Holds in the database, strains on the report:** formally the accepted name changes and the old becomes a synonym, so the alias is added, but on a lab report only one name prints and the other effectively disappears for that clinician.
2. "More names make it easier to find the same thing" — **True where synonyms are globbed, false where one name must be chosen:** NCBI/MycoBank/GBIF prove the findability half; CAP's checklist (valid, meaningful, feasible) proves the clinic half, where two names in circulation read as confusion, not help.
3. "Globbed into groups, like I'm trying to do" — **Documented foothold, affirmed:** synonym groups are exactly how the databases already work, so his glob method parallels real infrastructure, not wishful thinking.
4. "The purpose of the addition is findability" — **Partial — stability competes with findability:** the ISHAM group keeps *Candida auris* for unambiguous communication and surveillance continuity, which is a purpose beyond findability, and it is the stronger motive on the retention side.
5. "The old name never dies, it joins the glob" — **Dies slowly, lives unevenly:** it lives in databases and dies on reports that switch; the *Nakaseomyces glabratus* note (title carries both, body keeps the old) shows the afterlife is patchy, not guaranteed.
6. The findability vs. used-name split — **Both true, and it relocates rather than dissolves the fight:** his thesis wins findability, the retention case wins the used name, and the real contest moves to who gets to pick the one printed name (lab, per the 2026-10-10 note).

**My one extra (labeled mine):** the manuscript should state the thesis as "renaming adds; it does not erase *in the record*" — dropping the last three words is where the overclaim lives, and keeping them is what makes the retention side stop fighting the sentence.
