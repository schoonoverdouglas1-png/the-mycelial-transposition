# Old Disease Names × Modern Diagnostic Codes (2026-10-30)

**Frame:** creative manuscript reference only. Never medical advice. No diagnosis, no application to any person. Sequencing rules (principal vs. secondary, Excludes1/Excludes2, code-first notes) belong to professional coders — this table lays old names over the code list; it is not coding guidance.

**Commission (Oct 30, 2026):** "Make me a list of diagnostic codes cross reference with the most comprehensive list of oldest disease names that fits all the modern diagnostic coding." Interpretation: the most comprehensive old-names list is the 53-entry Long List, and every entry is cross-referenced here with its modern ICD-10-CM code(s). He may correct the interpretation.

**How to read:** American name FIRST, Latin second, per his naming doctrine. Tier tags on every claim: [D] documented · [H] his · [H→D] his with documented foothold · [LOGIC] inference with steps shown · [GAP] unknown. **Shiro column: PENDING on every data row** — Shiro is undefined, never invented, never guessed. Mapping quality is labeled on EVERY row — never present a guess as exact.

**Simply put:** Fifty-three old names filing into a much smaller set of modern code families. The old names multiply — five different names for tuberculosis, five for diphtheria — while the codes collapse, because a code names the germ and the place it showed up, never the old story about it.

## Part II — THE PATTERN

**What the mapping proves [LOGIC]:** the old names multiply and the codes collapse, exactly as the Oct 30 one-code theory says — a code names an organism and a site, never a serotype, never the old story about it. 53 rows (51 coded, 2 GAP) make 55 family-landings in the tally below — a SPLIT name counts once under each family it lands on, so landings exceed coded rows by 4 (Bilious fever lands on three families; Spotted fever and Putrid fever each land on two). The collapse is the point: the same germ wears five names in the old list and one code family in the new one.

**Aliases for ONE modern disease [LOGIC]:** Consumption + Phthisis + White plague + Galloping consumption + Lung sickness are five names for tuberculosis; template 0 + Throat distemper + Malignant sore throat + Bladder in throat + Membranous croup are five names for diphtheria. The old list preserves the names people used; the code list counts the disease once.

**One old name SPLIT across several modern diseases [LOGIC]:** Ague (malaria + other febrile diseases), Bilious fever (typhoid + malaria + hepatitis), Brain fever (meningitis + encephalitis), Bloody flux (shigellosis + amoebic dysentery), Spotted fever (RMSF + typhus), Putrid fever (typhus + sepsis). These are the names where the old story ran wider than any one disease.

**Mapping-quality tally [D]:** EXACT 9 · FAMILY 34 · SPLIT 6 · MANIFESTATION 2 · GAP 2 = 53.

**Simply put:** The old names are the stories people told about being sick. The codes are the filing system. Five stories can file under one code, and one story can file under three. Neither side is wrong — they are two maps of the same territory, and this table is the bridge between them.

## Part III — Flags, GAPs, Provenance

### Flags — carried, never silently fixed
1. **Template 0 vs. entries 6–9 [H]:** the Long List opens with a group form (template 0) that repeats the four throat names given individually as entries 6–9. Both are rowed here; the duplication is the Long List's own structure, not an error to collapse. Old-with-new: keep both.
2. **Lung fever [H→D]:** the old name was generic pneumonia; the Long List's fix narrows it to *S. pneumoniae*. The row carries BOTH J13 (per the fix) and J18.- (the generic family), so the narrowing does not erase the original breadth.
3. **Brain fever [H→D]:** the fix names *Neisseria meningitidis*, but the name historically covered meningitis and encephalitis broadly. Labeled SPLIT, not A39.0 alone — the fix does not shrink a syndromic name to one organism.
4. **Croup, twice, correctly [D]:** row 9 (membranous croup → A36.-, diphtheritic) and row 46 (croup → J05.0, viral obstructive laryngitis) are DIFFERENT codes for DIFFERENT diseases that share a word. Do not merge them.
5. **Milk sickness [D]:** T62.2X- is a FAMILY label only. No tremetol- or milk-sickness-specific ICD-10-CM code exists; the family is the nearest code, not an exact one.
6. **Hip gout [H]:** the old name records a misread (gout) at a site (hip). The row maps to osteomyelitis per the Long List's fix; the error itself is information and is kept, not corrected away.
7. **B95.3 — not used here [D]:** per the Shared Diagnostic Codes table, B95.3 (*S. pneumoniae* as cause of diseases classified elsewhere) pairs only with infection codes that do NOT themselves name the organism. Every organism row here already names its organism in its code (J13, G00.1, A40.3 pattern), so B95.3 has no place in this table. It is not an omission; it is the corrected usage applied.
8. **Toxemia [GAP]:** toxemia has no ICD-10-CM code (confirmed in his CMS list, Oct 18) and does not appear as a Long List entry; if it ever enters this table it enters as a GAP row, never with an invented code.
9. **Nostalgia [D]:** a dropped diagnosis — it has no modern code because modern medicine dropped the category, not because the code could not be found.

### GAPs
- **Day fever / diary fever (row 50) [GAP]:** sweating sickness, cause unknown, no ICD-10-CM code. The absence is the record's, not a failure of the search.
- **Nostalgia (row 52) [GAP]:** dropped diagnosis, no code.
- **Syndromic names with no single code (by design):** Brain fever, Ague, Bilious fever, Bloody flux, Spotted fever, Putrid fever — SPLIT rows, not GAPs; their codes are all listed, none is single.
- **No row was dropped.** All 53 Long List entries (template 0 + entries 1–52) appear in Part I.
